常见问题

有 macOS / Linux 版吗？

没有。Lumen 只做 Windows 版（10 / 11，64 位），所有能力都按桌面体验来做。

灵动岛能关掉吗？

可以。灵动岛默认关闭，在「设置 → 桌面」里打开；通知镜像有独立开关，且只读本机通知记录、不上传任何数据。

AI 助手要花钱吗？Key 给谁？

Lumen 本身免费，AI 功能自带钥匙（BYOK）：你在设置里填自己的 API Key，请求从你的电脑直连模型服务商，Lumen 没有中间服务器，也看不到你的对话。

更新怎么升？

应用会自动检查更新，有新版本时应用内一键下载升级，数据全部保留。

在哪里反馈问题？

到 GitHub Issues 提交，或在工作台「主界面 → 意见反馈」里直接说。
