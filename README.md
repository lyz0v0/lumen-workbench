# Lumen 工作台

本地优先的个人 AI 工作台。整个应用就是三个文件（`index.html` + `app.js` + `style.css`），浏览器双击 `Lumen.html` 即用；也可以用内置的 Electron 桌面壳跑成桌面窗口，或直接装 Windows 安装包。

> 当前版本 **v0.14.1** ｜ 55 个工具，已实装 29 个

![主界面](docs/screenshot-main.jpg)

## 特点

- **本地优先**：图片处理、PDF、二维码、文本工具全部在本机完成，文件不上传、不经过任何服务器
- **轻量无依赖**：三个文件即可运行，无框架、无后端、无注册
- **无需注册**：没有账号体系；AI 能力走 BYOK（自带 API Key，请求由壳主进程代发，密钥不出本机）
- **数据只存本机**：历史记录、AI 配置、价格备忘等全部保存在本地浏览器，卸载即清空
- **桌面壳可选**：`shell/` 是一个 Electron 轻量壳，做七件事——开窗口（走本地端口，与浏览器同源）、
  **本地端口服务**（启动即开 `http://127.0.0.1:17870`，浏览器打开就是同一个工作台；端口被占会先探明是哪个程序占的，再往后找空端口）、
  外链交给系统浏览器、代发联网请求（绕开跨域限制，热榜官方源 / AI 对话都走这条通道；浏览器侧由同源中继 `/__lumen/net`、`/__lumen/chat` 承接）、
  屏幕录制（列屏幕窗口源、录系统声音、直接落盘，实现见 `shell/rec.js`）、
  关窗口缩到托盘常驻（端口继续服务；托盘里可显示窗口 / 浏览器打开 / 复制地址 / 壳状态 / 重启端口 / 退出，再次打开壳会唤回窗口并重启端口服务）、
  **壳状态页**（`shell/status.html`：运行模式、端口、端口占用诊断、最近日志；它走本地文件加载，端口服务挂了也照样打得开）。
  想强制回到旧的 `file://` 模式：设环境变量 `LUMEN_MODE=file`，端口可用 `LUMEN_PORT` 改；开发调试用 `npm run dev`，走独立端口 17871 与独立数据目录，与正式实例互不干扰。
- **免费接口自动降级**：天气 / 汇率 / 热榜 / 快递等都备了备用源或多级兜底，挂了不影响其他功能

## 主界面

- **农历日历**：公历 + 农历双历、干支生肖、节气节日，纯本地计算不联网
- **实时汇率**：1 外币兑人民币，支持自选币种（最多 6 个），数据源为欧央行 Frankfurter，失败自动切换备用源
- **今日热榜**：与头条 App 同榜，窗口够宽时挂在右侧空白处，失败自动隐身
- **本地音乐**：把文件夹里的歌拖进来当工作 BGM，纯本地播放
- **搜索联想**：搜索框输入即匹配工具，↑↓ 选择回车直达
- **常用工具**：按最近使用自动排序，右键固定常用项
- **启动自检**：打开时自动检查本机环境（存储 / 画布 / 导出 / 剪贴板 / WASM / 网络等 7 项）与外部接口健康度，异常就在侧栏亮灯，可点开看明细，不阻塞使用
- **检查更新**：多源并发对比最新版本（raw / jsDelivr / GitHub API，任一可达即可），弹窗里直接给出「当前版本 ⟶ 最新版本」对比与更新方式说明，有新版一键前往下载
- **关于**：一句话简介 + 数据看板（工具 / 实装 / 分类数）+ 快速上手与快捷键 + 赞助入口

## 运行

**方式一：浏览器（最简单）**

双击 `Lumen.html` 即可，全部功能可用（`index.html` 是同一份文件的兼容名，作用相同）。

**方式二：一键启动（Electron 桌面窗口）**

双击仓库里的 **`setup.bat`**：首次运行会自动通过 npm 安装 Electron（国内自动走 npmmirror 镜像加速），装完自动打开桌面窗口；之后每次双击直接启动。需要本机已安装 [Node.js](https://nodejs.org)。

也可以手动安装启动：

```bash
npm install
npm start
```

> 桌面窗口会多出一条「主进程代发请求」通道：热榜官方源、AI 对话（部分服务商不返回跨域头）在浏览器直开方式下会自动走备用源，壳里则直接可用。

**方式三：Windows 安装包（推荐）**

在 [Releases · Latest](https://github.com/lyz0v0/lumen-workbench/releases/latest) 下载 `lumen-workbench-setup.exe`，双击安装：分步向导、可自选安装位置、自动生成开始菜单快捷方式。

- **应用内自动更新**：有新版本时，应用内「检查更新」即可下载并一键升级，数据全部保留
- 关闭窗口缩到托盘常驻，右键托盘图标可退出或打开壳状态页

## 说明

- 主界面的天气（Open-Meteo）、汇率（Frankfurter）、热榜、一言均为免费公开接口，失败会自动降级，不影响其他功能
- 快递查询使用免费的聚合接口，每天 30 次额度，超了次日恢复
- AI 工具走 BYOK：自带 API Key，请求由壳主进程直连服务商（浏览器方式走直连 + 备用源），本仓库不含任何 Key 与代理服务
- PDF、图片处理、二维码生成 / 解码等均为纯本地实现，不依赖任何第三方接口，文件不出本机
