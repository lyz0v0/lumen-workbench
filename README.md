# Lumen 工作台

本地优先的个人 AI 工作台。整个应用就是三个文件（`index.html` + `app.js` + `style.css`），浏览器双击即用；也可以用内置的 Electron 最小壳跑成桌面窗口。

> 当前版本 **v0.12.0** ｜ 50 个工具，已实装 21 个

![主界面](docs/screenshot-main.png)

## 特点

- **本地优先**：图片处理、PDF、二维码、文本工具全部在本机完成，文件不上传、不经过任何服务器
- **轻量无依赖**：三个文件即可运行，无框架、无后端、无注册
- **无需注册**：没有账号体系；AI 能力走 BYOK（自带 API Key，请求从本机直连服务商）
- **数据只存本机**：历史记录、AI 配置、价格备忘等全部保存在本地浏览器，卸载即清空
- **桌面壳可选**：`shell/` 是一个约 70 行的 Electron 最小壳，只负责开窗口和把外链交给系统浏览器
- **免费接口自动降级**：天气 / 汇率 / 热榜 / 快递等都备了备用源或多级兜底，挂了不影响其他功能

## 主界面

- **农历日历**：公历 + 农历双历、干支生肖、节气节日，纯本地计算不联网
- **实时汇率**：1 外币兑人民币，支持自选币种（最多 6 个），数据源为欧央行 Frankfurter，失败自动切换备用源
- **搜索联想**：搜索框输入即匹配工具，↑↓ 选择回车直达
- **启动自检**：打开时自动检查本机环境（存储 / 画布 / 导出 / 剪贴板 / WASM / 网络等 7 项）与外部接口健康度，异常就在侧栏亮灯，可点开看明细，不阻塞使用
- **检查更新**：自动对比最新版本，有新版一键前往下载
- **关于**：使用指南 + 全部工具清单（随版本自动同步）+ 赞助入口

## 运行

**方式一：浏览器（最简单）**

双击 `index.html` 即可，全部功能可用。

**方式二：Electron 桌面窗口**

```bash
npm install
npm start
```

> 国内网络下载 Electron 二进制慢的话，先设置镜像：
>
> ```bash
> # Windows (PowerShell)
> $env:ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"
> npm install
> ```

## 说明

- 主界面的天气（Open-Meteo）、汇率（Frankfurter）、热榜、一言均为免费公开接口，失败会自动降级，不影响其他功能
- 快递查询使用免费的聚合接口，每天 30 次额度，超了次日恢复
- AI 工具走 BYOK：自带 API Key，请求从本机直连服务商，本仓库不含任何 Key 与代理服务
- PDF、图片处理、二维码生成 / 解码等均为纯本地实现，不依赖任何第三方接口，文件不出本机
